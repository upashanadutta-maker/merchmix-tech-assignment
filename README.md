# Merchmix Technical Assignment

## Overview

This repository contains my submission for the Merchmix technical assignment. The project combines sales forecasting with an agentic AI workflow to identify promising source styles and propose three new garment concepts.

## Project Components

- Four-week sales forecasting for existing style-colour groups
- Evidence-based selection of three source styles
- Agent workflow for generating new garment concepts
- Validation checks and automated tests
- Final reports, outputs, and execution evidence

## Important Note

The forecast values belong to the existing source styles. They are not demand forecasts for the newly generated designs.
